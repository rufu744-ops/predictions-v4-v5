# V4-B 検証記録

実施日：2026-10-24（日本時間）。Python 3.12 / NumPy / pandas / SciPy。

## 自動検証

`python -m unittest discover -s tests -v`

15件成功。対象は合成データ・既知の確率計算であり、実市場の予測精度ではありません。

| 検証 | 結果 |
|---|---|
| Rと潜在状態を積分した周辺尤度 | 密な共分散行列による多変量Student-t尤度と一致 |
| 条件付きRのIG事後分布 | 密なガウス二次形式からの独立計算と一致 |
| logλの事後分布 | SciPyの独立した適応積分による正規化定数・平均と一致 |
| 日次ベイズ更新 | 同じグリッド・前処理での全データ一括再計算と一致 |
| 混合分布の予測区間 | 混合CDFで2.5%・97.5%に一致 |
| 全分散の法則 | 混合内分散＋混合間の平均差の分散と一致 |
| 情報のないλ | 尤度に情報がない場合に事前分布のまま保持 |
| 未解像の積分 | 成功扱いせず例外で停止 |
| h=1/5/20 | 成熟済みラベルだけを使い、学習するリターン区間は非重複 |
| 未来情報 | 未来の価格・特徴量を変更しても過去起点の予測平均・標準偏差は完全一致 |
| 状態更新 | 日次の再利用・月次再構築・入力訂正による再構築を確認 |
| 保存 | 同じ予測の再実行で上書き・二重保存しない |
| 満期後評価 | 引け前を評価しない、対象セッションのみ照合、同じ予測を二重評価しない |
| カバレッジ | 指定銘柄の不足時は本番予測を保存しない |
| 別アカウント用CSV | 状態・パラメータを除外し、改変検知・不変な再取り込みを確認 |
| 合成データ | 本番の結果投影から除外 |

15個のtestメソッドで複数の性質を確認しているため、表の行数とは一致しません。

## V4-AとV4-Bのダッシュボード共存

取得済みの統合版 `stock_forecast_integrated.zip` に含まれる実際の
`dashboard/data.py`・`dashboard/normalize.py` を使い、一時フォルダで確認しました。

1. 同じ合成入力でV4-AとV4-Bを別々に実行。
2. それぞれの予測・評価を別の結果専用フォルダへ投影。
3. 両者を同じダッシュボード用フォルダに取り込み。
4. 既存アダプタで6予測行を読込、6実績を結合。
5. v4a.0.1とv4b.0.1の両方の正規化アーカイブを生成。

推定方式の予測力を比較した試験ではなく、保存形式と取り込み処理の接続試験です。
最新V3完成版との入力接続や、外部Web画面への公開を検証したものではありません。
